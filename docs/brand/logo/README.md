# BurnLoop logo assets

Sourced from the Figma "Burnloop-export" file, uploaded directly to GitHub by the
brand owner. Each variant is provided as both SVG (preferred, scalable) and PNG.

| File | Use |
|---|---|
| `burnloop-icon-transparent` | Icon mark only (flame/droplet, purple gradient), transparent background — favicons, app icons, small avatars. |
| `burnloop-logo-main` | Full lockup: gradient icon + dark wordmark — for light backgrounds. |
| `burnloop-logo-white` | Full lockup, all white — for dark or colored backgrounds. |
| `burnloop-logo-white-text` | Icon (gradient) + white wordmark — for colored/photo backgrounds where the icon should stay on-brand but the wordmark needs to read as white. |

Brand color reference for use alongside these: `docs/brand/figma-brand-guidelines.md`.
